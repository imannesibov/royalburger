# Fast Food Restaurant Ordering System

## Project Description
This project is designed for educational purposes and is open to collaboration. It simulates a real-world fast food restaurant ordering system, where users can independently place an order, make a payment, and receive a receipt with an order number. The system uses Blink code: **123456** for payment.

Built using **Maven**, this project integrates core software engineering concepts to create a functional and user-friendly ordering system. The following key topics are implemented in the project:

- **Singleton Pattern**: Ensures a single instance of key classes, streamlining operations and enhancing code maintainability.
- **Working with Collections**: Utilizes Java collections (such as **List** and **Map**) to manage menu items, orders, and payments efficiently.

## Features
- **Self-service ordering system**: Users can browse through product categories and place orders.
- **Payment using Blink code**: Secure and easy payment with the Blink code system.
- **Order receipt**: After payment, the system generates a receipt with the order number for reference.
- **Menu management**: The system is able to manage and display items in different categories (e.g., Burgers, Beverages, and Desserts).

## Technologies Used
- **Java**: Core language for building the application logic.
- **Maven**: Dependency management and project setup.
- **Singleton Pattern**: For managing order services and ensuring only one instance of the cart/order process.
- **Collections (List, Map)**: For handling the menu, order items, and payments efficiently.
